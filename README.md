# Product Line Profitability & Margin Performance Analysis for Nassau Candy Distributor

## Overview

This project analyzes the profitability of different product lines sold by Nassau Candy Distributor using Python, Pandas, Matplotlib, and Streamlit.

The objective is to identify:

- High-profit products
- Low-profit products
- Revenue contribution
- Profit contribution
- Gross Margin %
- Profit per Unit
- Product-wise profitability

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit

Nassau Candy Distributor Sales Dataset

## How to Run

Install packages

```bash
pip install pandas matplotlib streamlit
```

Run Analysis

```bash
python main.py
```

Run Dashboard

```bash
python -m streamlit run dashboard.py
```
